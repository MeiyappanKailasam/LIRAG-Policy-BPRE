WHAT'S NEW:
  ✓ Single QUERY variable in config.py
  ✓ All scripts automatically use this query
  ✓ Change once, affects everything
  ✓ Alternative queries pool for quick testing

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

QUICK START:

1. CHANGE THE DEFAULT QUERY:
   
   Edit config.py (line 8):
   
   QUERY = "Your new question here?"

2. RUN ANY SCRIPT - IT USES THE NEW QUERY:
   
   python compare_models.py          # Uses new QUERY
   python -m src.agent               # Uses new QUERY  
   python -m evaluation.evaluation   # No change (reads from JSON)

3. USE ALTERNATIVE QUERIES IN CODE:
   
   from config import QUERY, ALTERNATIVE_QUERIES
   
   # Quick test different questions
   for alt in ALTERNATIVE_QUERIES.values():
       answer = policy_agent(alt)
   
   # Or specific ones
   ans = policy_agent(ALTERNATIVE_QUERIES['disability_scholarships'])

USAGE EXAMPLES:

Example 1: Use default query in your script
────────────────────────────────────────────
from config import QUERY
from src.agent import policy_agent

answer, clauses = policy_agent(QUERY)
print(answer['verified_answer'])


Example 2: Test all alternatives
────────────────────────────────────────────
from config import ALTERNATIVE_QUERIES
from src.agent import policy_agent

results = {}
for name, query in ALTERNATIVE_QUERIES.items():
    ans, _ = policy_agent(query)
    results[name] = ans['verified_answer']


Example 3: Add custom queries
────────────────────────────────────────────

In config.py, add to ALTERNATIVE_QUERIES:

ALTERNATIVE_QUERIES = {
    "my_query": "What is your new question?",
    "disability_scholarships": "...",
    # ... rest
}

Then use:

from config import ALTERNATIVE_QUERIES
answer = policy_agent(ALTERNATIVE_QUERIES['my_query'])
